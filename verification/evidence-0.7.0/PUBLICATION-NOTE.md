# Historical evidence / publication copy

These files record the pre-rebrand Esco 0.7.0 release. They are not results for
a newly built EscoF binary. Original binary hashes, variant names, timestamps,
numerical measurements, negative results and configuration values are retained.

Local absolute workspace prefixes have been replaced with `/local-build/` in
text records for publication. These paths are placeholders, not runnable paths.
`files.sha256.json` describes this publication copy, not the original unredacted
files. Hashes identifying measured server and benchmark binaries are unchanged.

No benchmark or runtime verification was executed for this packaging update.
