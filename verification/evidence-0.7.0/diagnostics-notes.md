# Diagnostic evidence scope

Kernel timing is not a server benchmark. kernel-timing.json measures the early A helper design. kernel-timing-b.json accidentally inherited an older generated escos.properties file from the kernel build folder, including the 8192 sort threshold; it is retained but is not evidence for the B defaults. kernel-timing-b-fresh.json reran the same comparison in a fresh settings directory; the actual properties are included. Production server runs always use independent fresh work directories and are unaffected by this diagnostic configuration mistake.

Initial and intermediate correctness logs are historical. The release correctness result is kernel-b-fresh.log. Later changes add only the caller-side NPC fallback; no primitive kernel code changed after that result.
